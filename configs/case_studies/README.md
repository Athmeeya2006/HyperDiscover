# Case-study data

`plankton_interp.csv`: interpolated (regular, ~3.35-day) time series of the Benincà et al. mesocosm experiment
(10 plankton groups + total N + PO4, 691 points), from the ReScience reproduction by Petchey, Plebani & Pennekamp
(2016), Zenodo doi:10.5281/zenodo.50213 (CC-BY-4.0; file data/original/interp_short_allsystem_original.csv).
The data file states: "these freely available data ... please cite the Ecology Letters publication of Beninca
et al. as source of the data" (Benincà, Jöhnk, Heerkloss & Huisman 2009, Ecology Letters — verify the citation).
Original study: Benincà et al. 2008, Nature 451:822–825, doi:10.1038/nature06512.
Copied here (small) so Kaggle kernels can run the case study from the code bundle.
